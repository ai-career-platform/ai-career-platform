# 다국어·날짜·접근성 표준 (T146)

> 상태: **PROPOSED**. 화면 언어는 지금처럼 한국어만 씁니다(`<html lang="ko">`).
> - 영어 문구는 대응표로만 준비했고, 언어 전환 기능은 켜지 않았습니다(PM 결정 필요).
> - 외부 i18n 라이브러리를 쓰지 않습니다. 브라우저 내장 `Intl`만 사용하므로 의존성·SBOM(T118) 변경이 없습니다.
> - 기존 화면 문구를 한꺼번에 바꾸지 않습니다. 새 화면과 수정하는 화면부터 적용합니다.

코드: `frontend/src/i18n/format.ts`(날짜·숫자), `frontend/src/i18n/messages.ts`(공통 문구)

## 1. 날짜·시각

| 규칙 | 방법 |
|---|---|
| **시간대를 반드시 명시** | `formatDateTime(iso)` / `formatDate(iso)`는 기본이 한국 시간(Asia/Seoul)입니다. `toLocaleString('ko-KR')`처럼 시간대 없이 쓰면 사용자 PC 시간대에 따라 날짜가 달라집니다 → **금지** |
| 한국 시간은 UTC+9 고정 | 1988년 이후 서머타임이 없습니다. 1월·7월 모두 +9로 시험합니다 |
| UTC로 보여 줄 때는 표시 | `formatDateTime(iso, { zone: 'utc' })` → 끝에 `UTC`가 붙습니다(운영 화면 등). 관리자 화면은 기존대로 `KST`를 붙입니다 |
| 날짜 전용 값(`YYYY-MM-DD`) | 지원일·마감일처럼 시각이 아닌 값은 `formatDateOnly(value)`. 시간대 변환을 하지 않습니다 |
| 날짜 입력 → 서버 조회 | `kstDayRangeUtc('2026-11-11')` → 한국 날짜 하루의 UTC 범위 `[시작, 다음 날 시작)` |
| 상대 시각 | `formatRelative(iso, now)` → `3시간 전`, `내일`. 기준 시각을 넘겨 시험이 결정적이게 합니다 |
| 잘못된 값 | 지어내지 않고 `—`(또는 지정한 fallback) |
| 마크업 | 날짜는 `<time dateTime={원래 ISO 값}>`로 감쌉니다. 화면 읽기 프로그램과 시험이 원래 값을 알 수 있습니다 |

표시 예(ko): `2026. 11. 11. 오전 12:30`(날짜+시각), `2026. 11. 11.`(날짜). en: `Nov 11, 2026, 12:30 AM`.

## 2. 숫자

| 함수 | 예 |
|---|---|
| `formatNumber(12345)` | `12,345` |
| `formatPercent(0.1234)` | `12.3%` (입력은 0~1 비율) |
| `formatBytes(1536)` | `1.5 KB` (1024 단위) |

NaN·Infinity·음수 크기는 `—`입니다.

## 3. 공통 문구

`t('state.error')`처럼 꺼냅니다. 상태 문구(불러오는 중·빈 화면·오류·다시 시도·권한·필수 입력·길이 초과)는 화면마다 다르게 쓰지 않습니다.
- ko/en 키가 같아야 하고, 빈 문구가 없어야 하며, 자리표시자(`{name}`, `{max}`)가 두 언어에서 같아야 합니다. 셋 다 시험으로 고정했습니다.
- HTML을 넣지 않습니다. React가 문자열로만 출력하므로 문구를 통한 스크립트 주입이 없습니다.
- 조사는 `을(를)`, `은(는)`처럼 병기합니다. 이름에 따라 바꾸는 처리는 하지 않습니다.

## 4. 긴 문자열·반응형

- 사용자가 입력한 이름·파일명처럼 길이를 모르는 값을 담는 상자에는 `overflow-wrap: anywhere`를 둡니다. 문서 카드·표·상태 패널에는 이미 적용되어 있습니다.
- 확인 폭: **320px**(가장 좁은 휴대폰, 200% 확대와 비슷), 375px(T117), 1280px.
- 기준: 가로 스크롤이 생기지 않아야 합니다(`scrollWidth ≤ innerWidth`).

## 5. 키보드·포커스·화면 읽기 프로그램

T89 자동 규칙(`frontend/src/a11y/AccessibilityRegression.test.tsx`)을 그대로 기준으로 씁니다.
- 컨트롤 이름, 버튼·링크 이름, `img alt`, 양수 tabindex 금지, 중복 id, `main`당 h1 1개, 건너뛰기 링크
- 모달: 포커스가 안으로 들어가고, Tab이 순환하고, Esc로 닫히고, 포커스가 원래 버튼으로 돌아옵니다
- 오류는 `role="alert"`로 알립니다

T146에서 브라우저로 더 확인하는 것:
- 첫 Tab에 "본문으로 바로가기"가 **보이는 상태로** 포커스되고, Enter를 누르면 `main#main-content`로 포커스가 옮겨집니다
- 키보드만으로 로그인할 수 있습니다

자동 점검은 실제 낭독 순서와 체감을 보장하지 않습니다. NVDA·VoiceOver 수동 낭독은 **NOT_RUN**입니다.

## 6. 이번에 고친 곳 (시간대 미지정)

| 화면 | 이전 | 이후 |
|---|---|---|
| 내 문서 – 등록일 | `toLocaleString('ko-KR')`(PC 시간대) | `formatDateTime` + `<time>` |
| 개인정보 설정 – 마지막 기록일 | 같음 | 같음 |
| 개인정보 설정 – 탈퇴 요청일·삭제 예정일 | 같음 | 같음 |

- 회귀 시험: 사용자 PC 시간대가 `Pacific/Pago_Pago`(UTC-11)일 때 이전 코드는 2026-11-10T15:30Z를 **11월 10일**로 보여 주어 시험이 실패하는 것을 확인했습니다. 이후 코드는 **11월 11일**(KST)입니다.
- 나머지 화면(알림·추천·지원 보드·기업 콘솔·공고·공개 포트폴리오·관리자·시장 추세)은 이미 `timeZone: 'Asia/Seoul'`을 명시하고 있어 그대로 두었습니다. 같은 일을 하는 화면별 포맷 함수는 이 모듈로 옮기는 것을 후속 정리로 제안합니다(동작 변화 없음, 이번 범위 아님).
