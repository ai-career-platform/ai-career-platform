| 단계 | 기준 |
|---|---|
| 접수 | 기능 ID·근거 문서·분류(KEEP/DEFER/DROP/NEW)·우선순위·선행 일감·영향(위 표 열)을 적어 이 매트릭스에 행을 추가 |
| 영향 검토 | DB/Migration·보안·Staging 열에 ●가 하나라도 있으면 PM과 해당 담당 리뷰를 필수로 함 |
| 승인 | PM 승인 기록(날짜·승인자·결정)을 기준선 §5에 남김. 승인 전에는 Mock·계약·격리 시험까지만 진행 |
| 구현 | 일감별 브랜치·PR, 독립 리뷰, CI PASS. Staging 변경은 별도 승인 |
| 사후 | 추적표(T04)·API 계약(T06)·데이터 사전(T05) 갱신, 릴리스 Gate(T90) 재판정 |
