# AI·ML·LLM·RAG/Agent 개발 가이드

## 기능 구상
기획 중인 ML 모델 7종:
1. 직무 적합도/매칭 점수
2. 개인화 랭킹
3. Skill Gap 분석
4. 사용자·직무 군집화
5. 채용시장 추세 예측
6. 사용자 행동 기반 추천
7. 이상 탐지

여기에 LLM 기반 문서 분석·설명, RAG, Tool Calling/Agent 워크플로가 결합됩니다. 목록은 현재 기획 범위이며 실제 서비스 완성 여부를 의미하지 않습니다.

## 모델 평가 및 계약
- 모든 예측 결과는 모델 버전/학습 데이터 기간/평가 지표/한계를 연결합니다.
- **매칭 점수는 취업·채용 성공 확률로 표시하지 않습니다.**
- 훈련/검증/테스트 분리 및 Leakage 점검, 데이터 출처·사용권한 확인.
- 개인화 추천에는 편향·공정성·설명 가능성 및 사용자 피드백 반영.
- AI 결과를 결정적 사실처럼 표현하지 않고 불확실성/제약을 UI에 표시.
- 실험 결과는 재현 가능한 Seed와 Artifact로 기록.

## LLM·RAG
- OpenAI 1차, Claude 등 대체 모델은 구성 가능하도록 설계하되 실제 연결 상태는 별도 확인.
- 요청 단위 Token/Cost/Latency/Model ID 로깅(민감정보 최소화).
- RAG 문서 접근 권한, Chunk 출처/버전, 검색 근거와 답변 근거 구분.
- Prompt Injection, 악성 파일, 과다 비용, 외부 API 실패 대응.
- Tool Calling에는 도구별 권한·승인·타임아웃·실행 기록을 적용.
- AI API 장애는 핵심 화면/API 중단으로 전파하지 않고 안전한 대체 흐름 제공.
