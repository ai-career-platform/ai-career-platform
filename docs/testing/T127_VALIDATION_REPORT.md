## 1. 화면 `/company/postings?org=…` (UI-N08 제안)

| 요소 | 내용 |
|---|---|
| 진입 | 기업 콘솔(T124)의 조직 상세에서 "공고 관리" 링크. 조직을 고르지 않으면 안내와 콘솔 링크 |
| 목록 | 제목·상태 배지·마감일, **상태별 필터**(전체·초안·검수 대기·반려·게시 중·마감·만료·운영 내림, 건수 표시), 수정본 표시 |
| 초안·반려 | 편집 폼(제목·설명·고용형태·근무지·https 지원 링크·마감일 ≤ 60일). 반려는 **사유 코드 이름 + 운영자 설명** 표시, 고치면 초안으로 |
| 검수 대기 | "철회해야 수정 가능" 안내 + 철회 |
| 게시 중 | 수정본 만들기(승인 전까지 공개 내용 그대로), 마감(확인 대화상자) |
| 종료 상태 | 보기만, "새 초안을 만드세요" |
| **없는 것** | 게시·승인·반려·내림 버튼(기업 화면에는 없음 — 운영 검수 결과로만 바뀜) |
| 오류 | 403 "운영 확인이 끝난 조직만 검수 요청", 404 "찾을 수 없거나 권한 없음", 409 "다른 사람이 먼저 바꿈 → 최신 불러옴", 422 "필수 항목·https" |
