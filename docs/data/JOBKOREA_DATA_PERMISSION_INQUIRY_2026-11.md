## 2. 발송용 본문 (PM 확인 후 발송)

**제목:** [제휴·데이터 이용 문의] AI Career Platform 의 잡코리아 채용공고 데이터 이용(API·라이선스·수집 허가) 가능 여부

안녕하세요. 저희는 AI Career Platform 이라는 커리어 추천 서비스를 개발하고 있습니다. 잡코리아 채용공고 데이터를 정식으로 이용할 수 있는 방법을 문의드립니다.

**1) 서비스 소개**
- 구직자의 경력·기술을 분석해 맞는 직무와 채용공고를 추천하고, 부족한 역량을 안내하는 웹 서비스입니다(현재 개발·시험 단계, 공개 운영 전).
- 운영 형태: 자체 서버(Google Cloud)의 웹 서비스. 공고 원문을 재판매·재배포하지 않습니다.

**2) 데이터 활용 목적**
- 공고 검색·목록 표시, 사용자 역량과 공고의 매칭·추천, 직무별 수요 통계(집계값).
- 상세 내용은 잡코리아 원문 페이지로 연결해 제공합니다.

**3) 필요한 필드 (최소)**
공고번호, 원문 URL, 공고 제목, 기업명, 근무지, 고용형태, 등록일, 마감일, 공고 상태(진행/마감).
필요하면 경력·학력 조건과 직무 분류를 추가로 요청할 수 있습니다. 공고 본문 전문, 이미지, 담당자 연락처 등 개인정보는 요청하지 않습니다.

**4) 수집 목표와 규모**
- 하루 **신규** 공고 최대 약 1,000건을 **목표**로 하고 있습니다. 확보 보장 수치가 아니며, 허용해 주시는 범위 안으로 맞추겠습니다.
- 웹페이지 수집을 허용해 주시는 경우의 계획 상한:
  - 하루 최대 약 1,300회 요청(검색 결과 페이지 약 60~200회 + 상세 페이지 약 1,000회 + robots.txt 1회)
  - 요청 간격 최소 2초(또는 robots.txt crawl-delay 중 큰 값), 동시 접속 1개
  - 야간(21:00~08:00 KST) 1회 실행
  - 403/429/CAPTCHA 응답이 오면 즉시 중단하고, 차단·제한을 우회하지 않습니다
- API·데이터 피드를 제공해 주시면 웹 수집 대신 그 방식만 쓰겠습니다.

**5) 수집 주기와 중복 제거**
- 하루 1회입니다.
- 공고번호로 중복을 제거하므로 이미 받은 공고의 상세는 다시 요청하지 않습니다.
- 변경 확인이 필요한 기존 공고만 제한된 수(예: 하루 200건 이하)로 다시 조회합니다.

**6) 출처 표시**
목록·상세 화면에 "출처: 잡코리아"와 원문 링크를 표시합니다. 잡코리아가 정하는 표시 방식(로고·문구)을 따르겠습니다.

**7) 보관·삭제 정책**
- 정규화한 필드만 저장하고 HTML 원문은 장기 보관하지 않습니다.
- 마감된 공고는 마감 후 N일(협의) 안에 서비스에서 내리고, 이후 삭제합니다.
- 잡코리아가 요청하면 해당 데이터를 즉시 삭제하고 수집을 중단합니다.

**8) 서비스 제공 방식**
로그인 사용자에게 추천·검색 결과로 보여 줍니다. 외부에 API 로 다시 제공하지 않습니다.

**9) 문의 사항**
1. 위 목적에 쓸 수 있는 **공식 API, 데이터 피드 또는 유료 라이선스(제휴 계약)** 가 있습니까? 이용 조건·비용·호출 한도·신청 절차는 어떻게 됩니까?
2. API 가 개인·일반 기업에 제공되지 않는다면, **웹페이지 자동 수집을 위 범위로 허용**받을 수 있습니까? 가능하다면 허용 요청 수·시간대·User-Agent·대상 경로(/Search, /Recruit/GI_Read)를 알려 주십시오.
3. 필드별 저장·정규화·서비스 표시·추천(AI 분석 포함)의 허용 범위와 보관 기간·삭제 의무는 어떻습니까?
4. 출처 표시 방법과 그 밖에 지켜야 할 조건이 있습니까?
5. 허용이 어렵다면 그 사실만 알려 주셔도 됩니다. 그 경우 잡코리아 데이터를 수집하지 않겠습니다.
