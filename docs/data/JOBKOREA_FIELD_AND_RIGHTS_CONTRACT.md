## 0. 프로젝트 성격 및 학습용 운영 정책 (PM 방향, 2026-11-07)

**목적:** 상용 서비스 운영이나 채용공고 재배포가 아니라, 내부 단기 실습에서 잡코리아 공개 채용공고의 구조를 이해하고 **수집 → 정규화 → 중복·만료 검증 → PostgreSQL 실습 → 기술스택/직무 분석** 과정을 학습한다.

**범위:** 잡코리아 한 곳만. 외부 사이트 추가, 유료 서비스, 공개 데이터셋 제공, 타인에게 원문 배포, 수집 정보로 모델을 외부 제공하는 행위는 포함하지 않는다. 비상업적 학습 목적도 이용약관·접근 제한·저작권·개인정보 규정을 면제하지 않는다.

### 학습용 최소 수집 운영 규칙 (제안, 실제 사이트 접근 전 승인 필요)

| 영역 | 내부 규칙 |
|---|---|
| 학습 데이터 | 허용 확인된 **공개 채용공고**의 필요 최소 항목만. 가능하면 메타데이터·출처 URL 위주; 원문·이미지·첨부 대량 복제 금지 |
| 실행 순서 | 합성 Fixture로 Parser/DTO/DB/품질 테스트 선행 → 사이트별 조건 검토 → PM 승인된 학습 범위에 한해 소량 실수집 |
| 접근 통제 | 로그인 세션·인증 쿠키·유료/비공개 경로·CAPTCHA/차단 우회, 요청 위장, 비공개 API 역공학 금지 |
| robots/약관 | 정확한 요청 경로별 robots.txt 및 웹사이트 이용 조건 기록. robots 허용만으로 법적·저작권 허가가 완성되지는 않음 |
| 트래픽 | 수동으로 1회 소량 샘플부터. 병렬·대량 순회·자동 반복/03:00 정기 배치는 별도 검토까지 금지. 403·429·CAPTCHA·차단·접근금지 신호 발생 시 즉시 중단 |
| 개인정보 | 채용 담당자 개인 이메일/전화번호 등 불필요 개인정보 기본 수집 금지; 분석 결과도 개인을 식별하지 않도록 처리 |
| 저장·보관 | 접근 통제된 로컬/격리 학습 DB. 최소 컬럼·최소 보존 기간을 실습 전 명시, 종료 시 폐기. 원문 공개·재판매·재배포 금지 |
| 변경 관리 | PM이 대상 URL 패턴·필드·최대 건수·요청 간격·보존 기간·승인 일자·검토 근거를 실행기록에 남김. 범위 확대는 재승인 |
| 금지/불명확 | 대상 URL 자동수집 금지 또는 권리/약관 적용이 불명확하면 **실수집 HOLD**; 합성 fixture/공식 허용 데이터로 실습 |

### 수집 실행 게이트 (현재 미충족)

- [ ] 대상 URL(검색 목록/상세)의 **웹사이트** 약관·robots.txt·접근 제한을 각각 확인하고 근거 URL·검토일 기록
- [ ] API 약관과 웹 크롤링 규칙의 적용 범위를 구분하고, 금지/별도 허가 조항 여부 확인
- [ ] 허용 가능한 최소 필드, URL 패턴, 최대 수집 건수·실행 횟수·요청 간격을 PM이 명시
- [ ] 로컬 DB 위치·접근권한·보존 기간·폐기 방법 및 개인정보 배제 규칙 확인
- [ ] 차단 신호(403/429/CAPTCHA/robots 제한/약관 금지) 중지 조건 구현·검증
- [ ] PM의 **학습용 제한 수집 실행 승인** 확보
- [ ] 별도 계약/서면 허가가 필요한 이용 범위라면 해당 근거 확보, 아니면 필요하지 않다는 검토 결과를 기록

**게이트 상태: NOT_READY.** 이 문서 작성·PR·CI PASS는 실사이트 수집 허가가 아니다. 해당 게이트가 해결되지 않더라도 합성 데이터로 T62~T64 학습 개발은 가능하다.

**참고:** 잡코리아의 [채용정보 API 약관](https://www.jobkorea.co.kr/network/Popup_Xml.asp)은 별도로 제한을 명시한다. 웹페이지에 대한 별도 이용 조건을 아직 확정적으로 확인하지 못했으며, 따라서 이 문서는 **웹 크롤링이 허용된다는 법률 판단이 아니다**.

## 1. 공식 확인 근거와 현재 판단

- **잡코리아 채용정보 API 신청 및 약관:** https://www.jobkorea.co.kr/network/Popup_Xml.asp (열람일 2026-11-07, 페이지상 시행일 2025-03-26)
- **실제 대상 화면 예시:** https://www.jobkorea.co.kr/Search/?stext=ax&tabType=recruit (PM 제시). 검색 결과 페이지의 기업/제목/지역/경력/등록·마감·급여 등의 표시 항목을 **필드 후보로만** 사용. DOM selector·응답 API·페이지별 추출 성공은 검증하지 않았다.
- **API 신청 화면:** 공공기관/학교 중심으로 제공하며, 이용 기관·사이트·서버 IP·사용목적 등을 입력하게 되어 있다.
- **API 약관 제5조 4항:** 개인/일반기업 및 프로젝트·개인 사용·유료화·DB 수집 목적으로는 이용신청을 승낙하지 않는다고 명시.
- **API 약관 제6조:** 승인 후 호출링크·가이드를 제공하며 등록 IP 범위 내 사용, 진행 중 공고만 제공. 1회 최대 500건, 일일 호출 횟수 제한 없음이라고 명시. **이 수치는 API 약관에만 적용되며 웹 페이지 크롤링 허용량을 의미하지 않는다.**
- **API 약관 제7조 2~5항:** BI/출처 표기, 합의 사이트 이외 사용 제한, 제공 정보의 수정·재가공·별도 복제·저장 금지 및 영업활동 제한.
- **API 약관 제9~10조:** 사전 서면 동의 없는 가공·이용 및 제3자 제공·양도 제한.
- **API 약관 제11조:** 위반 시 중단·해지 및 해지 시 폐기 요구.
- **적용 경계:** 위 규정은 확인한 **API 이용약관**의 내용이다. **웹페이지 직접 크롤링**에 동일한 API 전용 호출 규칙을 적용한다고 단정하지 않는다. 웹사이트 이용약관·robots.txt·접근통제·권리자 동의 등을 별도로 평가해야 한다. 이 확인이 완료되지 않았으므로 웹 크롤링도 **HOLD**.

### 결정

**현재 계획한 독립 Batch Worker → 정규화 → PostgreSQL 저장 → 서비스 검색/매칭/AI 분석 흐름을 허용하는 명확한 사용권한은 확인되지 않았다.** API 약관에는 DB 수집·저장·재가공 제한이 명시되어 있어 해당 API 계약의 명시적 예외 없이 API 기반 실연동을 진행하면 안 된다. **일반 공개 웹페이지의 크롤링은 별도 사안으로, API 약관만으로 일률적인 서면 허가 의무를 단정하지 않는다.** 웹사이트에 실제 적용되는 이용 조건·robots.txt·접근 제한·데이터 권리를 확인하고 그 결과에 따라 제한적인 학습 수집 가능 여부를 PM이 판단한다.

'화면 관찰'은 공개 검색 결과 예시 또는 PM 제공 화면에서 볼 수 있는 표현을 의미한다. **모든 필드의 실제 저장·서비스 사용 권한은 미승인**이며 파싱 규칙/타입은 T62/T63 설계 후보이다.

| 필드 후보 | UI·요구사항 대응 | 중요도 | 정규화 후보 | DB 매핑 후보 / 확인 필요 |
|---|---|---|---|---|
| `source_code` | 데이터 출처 | 필수 | `jobkorea`(후보 code, DB Seed 미등록) | `data_sources.code`; 승인 전 생성 금지 |
| `external_posting_id` | 원문 식별/중복 | 필수(수집 단계) | 문자열; 안정성 미검증 | `job_posting_external_refs.external_id`(조건부 설계) |
| `source_url` | 원문 상세 링크 | 필수(서비스 연결) | 허용 도메인 URL | `job_postings.source_url` |

| `employment_type` | 정규직/계약직 등 | 권장 | 기존 허용 값으로 매핑; 불일치 기록 | `job_postings.employment_type` |
| `salary` | 임금·급여 (표시된 경우) | 선택 | 금액/단위/비공개 상태 구분 | 현재 C02 직접 컬럼 없음; 자동 추가 금지 |

| `detail_text` | 업무·자격·우대사항 | 조건부 | 전체 본문 저장 대신 필요한 허가 필드만 추출 검토 | `job_postings.description`; 저작권/저장·가공 권한 명시 필요 |

**배제/제한 후보:** 지원자/담당자 이름·직통번호·개인 이메일·이력서, 인증 쿠키·토큰, 로그인 전용/비공개 정보, 이미지·첨부 원본, 불필요한 개인식별정보. 공고의 전화/이메일이 공개되어 있다는 사실만으로 자동 저장·재사용을 승인하지 않는다.

**필드 설계 범위:** 매핑 후보는 데이터 사전의 승인된 운영 Schema가 아니라 현재 문서상 **DRAFT/검증용 구조**이다. 이번 단계에서 DB 테이블/컬럼, Seed, API Spec, 코드 변경 없음.
