안녕하세요. AI Career Platform이라는 내부 학습용 소프트웨어 개발 프로젝트를 진행하고 있습니다.

저희는 잡코리아의 공개 채용공고를 참고하여 채용정보 추출 프로그램의 정확도를 검증하는 기술 실습을 계획하고 있습니다. 실제 서비스를 운영하거나 공고를 재판매·배포하려는 목적은 아닙니다.

대상 예시 URL은 아래 **한 건**입니다.

https://www.jobkorea.co.kr/Recruit/GI_Read/50246410

해당 공고의 HTML을 허용된 방식으로 1회 확보하여 공고명, 회사명, 근무지, 고용형태, 경력, 학력, 급여, 등록일/마감일 등 표시 정보의 추출값과 사람이 확인한 정답을 내부에서 비교할 수 있는지 문의드립니다.

현재는 합성 데이터로만 프로그램을 시험했고, **실제 잡코리아 공고를 자동 수집하거나 해당 공고 HTML을 저장·분석하는 작업은 시작하지 않았습니다.**

다음 항목을 구분하여 안내해 주시면 감사하겠습니다.

1. 비로그인 공개 상세 페이지의 **단일 1회 자동 요청**이 허용되는지, 또는 수동 HTML 저장·제공받은 샘플만 허용되는지
2. 정확도 비교 목적의 HTML **일시 보관**(접근통제, SHA-256 무결성 기록 포함)과 보존기간·삭제 의무
3. 공고명·기업명·공고번호·원문 링크·근무지·고용형태·경력·학력·급여·게시/마감일 등 **필드별 추출·정규화·내부 비교**의 허용 범위
4. 개인/기업회원 이용약관 및 기타 웹페이지 이용 조건의 적용 범위(비회원 접근 포함), 사전 동의·별도 계약이 필요한 사용 행위
5. 실제 사용하는 User-agent, robots.txt, 요청 횟수·속도 및 자동 요청 중단 조건
6. 향후 PostgreSQL 저장·검색·추천·AI 분석·서비스 표시 등 **반복 수집/서비스 활용**은 단일 검증과 별도로 허용받아야 하는지
7. 승인 가능하다면 허용 범위, 책임 담당자, 관련 약관/허가 문서, 유효기간 및 철회·삭제 절차

단일 실습 정확도 검증도 허용되지 않는다면 진행하지 않겠습니다. 별도 담당 부서 또는 권리자 승인 절차가 있다면 연결 방법을 안내 부탁드립니다.
