## 5. 불변 조건 (시험으로 고정)

| ID | 조건 |
|---|---|
| INV-1 | 기업 역할은 조직 단위다. 전역 역할(`career.user_roles`)로 부여하지 않는다 |
| INV-2 | 기업 역할은 운영 관리자 권한(`admin.*`)을 갖지 않는다 |
| INV-3 | 공고 게시·반려는 운영 관리자만 한다. 기업 역할에 검수 우회·즉시 게시 권한이 없다 |
| INV-4 | 후보자 비공개 정보·검색·연락·지원 기록은 어떤 역할에도 허용하지 않는다(승인 전) |
| INV-5 | 다른 조직의 리소스는 존재를 숨긴다(404). 같은 조직 안에서 역할이 부족하면 403 |
| INV-6 | 조직에는 active owner가 최소 1명 있어야 한다. 마지막 owner의 강등·제외·탈퇴는 409로 거부한다 |
| INV-7 | owner는 기업 역할 중 최고다. 기업 역할로 `admin`을 부여할 수 없다 |
| INV-8 | 검증 전(`pending`)·정지(`suspended`) 조직의 멤버는 조직 열람·공고 초안 외 행동을 할 수 없다 |
| INV-9 | 운영 관리자는 기업 공고 내용을 직접 수정하지 않는다(반려·내림만) |

추가로 시험이 확인하는 것은 다음과 같습니다.
- 기업 담당자 권한은 기업 관리자 권한의 부분집합입니다.
- 구직자는 기업 기능 중 등록 신청과 초대 수락만 할 수 있습니다.
- 비로그인 사용자는 게시 공고와 동의 범위 조회만 할 수 있습니다.

## 6. 조직 상태와 허용 행동 (INV-8)

| 조직 상태 | 멤버가 할 수 있는 것 |
|---|---|
| `pending`(검증 대기) | 콘솔 열람, 공고 **초안 작성·수정·열람**(검수 요청·초대 불가), 멤버 목록, 탈퇴, 등록 취소(종료) |

| `closed`(종료) | 없음. 멤버 권한 회수, 공고 마감 |
