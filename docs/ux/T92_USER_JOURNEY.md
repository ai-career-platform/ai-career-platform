## 5. 내비게이션 게이트 (회귀 방지)

- **모든 앱 안 링크는 정의된 경로를 가리켜야 함**: 알려진 공백 2개만 예외입니다. 공백이 고쳐지면 목록에서 지워야 합니다.

- **변이 확인**: J-1 수정을 되돌리면 게이트가 고아 경로 3개를 정확히 찾아 실패했습니다(확인 후 복원).
