# Model Card — 사용자 군집 baseline (T74, ML04)

| 항목 | 내용 |
|---|---|
| 이름 / 버전 | `kmeans_skill_vector` / `segmentation_version=t74.1`, `feature_version=skill_vector.v1` |
| 상태 | **실험용 baseline · 서비스 미적용** (PARTIAL, 합성 데이터 전용) |
| 담당 | 미배정 (작업지시서 기준) · 평가 자료: [T74_SEGMENTATION_BASELINE.md](T74_SEGMENTATION_BASELINE.md) |
| 코드 | `ml/segmentation/baseline.py` |

## 목적과 사용 범위
- 허용된 기술 숙련도 특징으로 사용자를 비슷한 그룹으로 나눠 **집계 수준의 세그먼트**를 만드는 첫 기준선입니다(AI 시스템 구조 ML04, F-025).
- 용도: 운영자가 세그먼트 규모·특징을 이해하는 집계 분석. **개인에게 결과를 보여주거나, 개인별 혜택·불이익·추천 결정에 자동 사용하지 않습니다.**
- 범위 밖: 개별 사용자 라벨링, 신용·채용 판단, 민감속성 추정, 이상 탐지(T77).

## 모델
- k-means(k-means++ 초기화, 5회 재시작, seed 고정)로 결정적입니다. k는 5명 미만 군집이 없는 후보 중 silhouette이 가장 큰 값을 고릅니다.
- 입력 특징: 기술 숙련도(1~5)/5, 미입력 0.

## 데이터
- 학습·평가 모두 T147 합성 공장 데이터(`synthetic_seed`)입니다. 실사용자 데이터·이력서 원문·행동 로그는 사용하지 않았습니다.
- 동의하지 않은 행(`consent=false`)과 기준 시각 이후 이용 가능한 행은 제외합니다.
- 민감·식별 속성이 입력에 있으면 거부합니다.

## 한계·위험
- 합성 데이터의 희소 특징(사용자당 3개)에 대한 결과라 **실서비스 성능을 보장하지 않습니다.** 안정성도 목표에 못 미쳐 현재는 운영 판단 근거로 쓰지 않습니다.
- 군집 번호에는 의미가 없고, 사람이 읽는 이름은 정해지지 않았습니다.
- **편향:** 성별·나이 등은 특징으로 쓰지 않지만, 기술 분포가 집단과 상관되면 간접 영향이 생길 수 있습니다. 집단 라벨이 확보되면 표현 비율(0.5~2.0 제안)로 점검하며, 이 점검은 합성 집단으로만 테스트했습니다.
- 작은 군집은 재식별 위험이 있어 5명 미만이면 크기를 숨깁니다(T71 k=5, 제안).
- 동의 철회·삭제가 이미 학습·집계된 결과에 반영되는 절차는 미확정입니다(T25 P0 OPEN). 실데이터 사용 전에 정해져야 합니다.

## 승인 필요 사항
임계값, 실데이터 출처와 동의 정책(T71), 결과 저장 위치, 세그먼트 이름 규칙, 개별 노출 금지 정책의 확정.
