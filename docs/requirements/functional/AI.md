### FR-AI-001 문서 업로드·관리

| 항목 | 내용 |
|---|---|
| 요구사항명 | 이력서·포트폴리오 파일 업로드, 목록, 삭제 |
| 우선순위 | Should |
| 사용자 스토리 | 구직자로서, 이력서 파일을 올려 두고 싶다. 직접 입력하지 않고 분석을 받기 위해서다. |
| 설명 | PDF·DOCX 파일을 올리면 안전 검사 후 사용할 수 있는 상태가 된다. 파일은 API 서버와 분리된 파일 저장소에 실행할 수 없는 상태로, 추측할 수 없는 이름으로 저장한다([NFR-SEC-003](../non-functional/NON_FUNCTIONAL.md#nfr-sec-003-업로드-파일-보호)). 문서를 삭제하면 원본, 분석 결과, 검색용 자료까지 모두 지운다. |
| 입력 | 파일(PDF·DOCX, 최대 10MB), 문서 종류(이력서·포트폴리오) |
| 출력 | 문서 목록(파일명, 종류, 크기, 상태, 올린 시각) |
| 선행 조건 | 로그인 상태 |
| 수용 기준 | 1. 확장자가 아니라 실제 파일 내용으로 형식을 확인한다.<br>2. 검사 중에는 "검사 중" 상태를 보여주고, 끝나면 "사용 가능" 또는 "거부됨"으로 바뀐다.<br>3. 삭제 후에는 해당 문서가 목록·분석·Q&A 근거 어디에도 나오지 않는다.<br>4. 다른 사용자의 문서는 조회·삭제할 수 없다.<br>5. 화면에는 사용자가 올린 원래 파일 이름을 보여주지만, 저장소의 파일 이름은 무작위 값이다. |
| 예외 처리 | 10MB 초과: "10MB 이하 파일만 올릴 수 있습니다". 지원하지 않는 형식: "PDF 또는 DOCX 파일만 올릴 수 있습니다". 검사 실패: "거부됨"과 이유 표시. |
| 관련 화면 | UI-019 문서 관리 |

### FR-AI-002 이력서 분석과 반영

| 항목 | 내용 |
|---|---|
| 요구사항명 | AI로 이력서에서 기술·경력을 추출하고 사용자가 골라 반영 |
| 우선순위 | Should |
| 사용자 스토리 | 구직자로서, 이력서에서 기술을 자동으로 뽑아 보고 맞는 것만 내 기술에 넣고 싶다. 기술을 하나씩 입력하는 수고를 줄이기 위해서다. |
| 설명 | 올린 문서를 AI로 분석해 기술 후보(제안 숙련도, 근거 문장), 경력 후보, 요약을 보여준다. 사용자가 선택한 항목만 프로필에 반영한다. 분석은 시간이 걸리므로 진행 상태를 보여준다. |
| 입력 | 분석할 문서, 분석 종류(기술 추출·요약), 반영할 기술과 숙련도 |
| 출력 | 분석 상태(대기·진행·완료·실패), 추출 결과, 사용 모델, 반영 후 보유 기술 |
| 선행 조건 | 로그인 상태, 문서 상태 "사용 가능", AI 처리 동의 |
| 수용 기준 | 1. 분석 결과는 사용자가 확인하기 전에는 프로필에 자동 반영되지 않는다.<br>2. 결과에 사용한 모델과 분석 시각을 표시한다.<br>3. 기술 후보마다 문서 속 근거 문장을 보여준다.<br>4. AI 처리 동의가 없으면 동의 화면으로 안내한다. |
| 예외 처리 | 분석 실패·시간 초과: "분석하지 못했습니다. 다시 시도해 주세요"와 다시 시도 버튼. 읽을 수 없는 문서: 원인 안내. |
| 관련 화면 | UI-020 문서 분석 결과 |

### FR-AI-003 근거 기반 커리어 Q&A

| 항목 | 내용 |
|---|---|
| 요구사항명 | 내 문서와 공용 자료를 근거로 커리어 질문에 답변 |
| 우선순위 | Could |
| 사용자 스토리 | 구직자로서, 커리어 질문을 하면 근거가 있는 답을 받고 싶다. 출처를 확인하고 믿을 수 있는 정보를 얻기 위해서다. |
| 설명 | 질문과 관련된 내용을 내 문서와 운영팀이 올린 공용 커리어 자료에서 찾아 답변하고, 근거 문서와 위치를 함께 보여준다. |
| 입력 | 질문(2~1,000자), 검색할 문서(선택) |
| 출력 | 답변, 근거 목록(문서명, 위치, 관련도), 한계 설명 |
| 선행 조건 | 로그인 상태 |
| 수용 기준 | 1. 모든 답변에 근거가 1개 이상 있다. 근거를 찾지 못하면 답변하지 않는다.<br>2. 다른 사용자의 문서는 근거로 쓰지 않는다.<br>3. 문서 속에 적힌 지시문을 따라 동작하지 않는다.<br>4. 질문 원문은 저장하지 않는다. |
| 예외 처리 | 근거 없음: "관련 근거를 찾지 못했습니다". AI 장애·시간 초과: Q&A 영역만 오류 표시. |
| 관련 화면 | UI-022 커리어 Q&A |

### FR-AI-004 AI 작업 실행과 승인

| 항목 | 내용 |
|---|---|
| 요구사항명 | 정해진 AI 작업 실행과 단계별 사용자 승인 |
| 우선순위 | Could |
| 사용자 스토리 | 구직자로서, 반복 작업(예: 목표 직무 공고 요약)을 AI에게 맡기되 결과를 저장하는 단계는 직접 승인하고 싶다. 원하지 않는 변경을 막기 위해서다. |
| 설명 | 허용된 작업 목록 중 하나를 실행한다. 데이터를 바꾸는 단계 전에는 사용자 승인을 받고, 모든 실행 단계를 기록한다. 1차 작업 목록은 PM이 확정한다. |
| 입력 | 작업 종류, 승인·거절 |
| 출력 | 실행 상태, 승인 요청, 단계별 실행 기록 |
| 선행 조건 | 로그인 상태, AI 처리 동의 |
| 수용 기준 | 1. 승인 없이 데이터를 바꾸는 단계를 실행하지 않는다.<br>2. 승인 요청은 정해진 시간(30분)이 지나면 만료된다.<br>3. 같은 요청을 두 번 보내도 작업은 한 번만 실행된다.<br>4. 실행 기록을 화면에서 확인할 수 있다. |
| 예외 처리 | 승인 만료·거절: 작업 중단 안내. 실행 한도 초과: 잠시 후 다시 시도 안내. |
| 관련 화면 | UI-023 AI 작업 내역 |
