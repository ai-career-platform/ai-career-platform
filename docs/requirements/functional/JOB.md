### FR-JOB-001 직무 검색

| 항목 | 내용 |
|---|---|
| 요구사항명 | 직무 목록 조회·검색 |
| 우선순위 | Must |
| 사용자 스토리 | 방문자로서, 어떤 직무가 있는지 검색하고 싶다. 내가 목표로 할 직무를 찾기 위해서다. |
| 설명 | 운영 중인 직무를 이름으로 검색하고 목록으로 보여준다. 로그인하지 않아도 볼 수 있다. |
| 입력 | 검색어(선택, 최대 100자), 페이지 이동 |
| 출력 | 직무 목록(이름순, 한 번에 20개) |
| 선행 조건 | 없음 |
| 수용 기준 | 1. 같은 검색 조건이면 항상 같은 순서로 보여준다.<br>2. 운영을 중단한 직무는 목록에 나오지 않는다.<br>3. 다음 페이지 이동 시 중복·누락이 없다. |
| 예외 처리 | 검색 결과 없음: "검색 결과가 없습니다" 안내. |
| 관련 화면 | UI-006 직무 목록·상세 |

### FR-JOB-002 직무 상세

| 항목 | 내용 |
|---|---|
| 요구사항명 | 직무 설명과 요구 기술 조회 |
| 우선순위 | Must |
| 사용자 스토리 | 방문자로서, 직무가 어떤 일을 하고 어떤 기술이 필요한지 보고 싶다. 준비할 기술을 알기 위해서다. |
| 설명 | 직무 설명과 요구 기술 목록(기술별 요구 수준 1~5)을 보여준다. 로그인 사용자는 목표 직무로 추가할 수 있다. |
| 입력 | 직무 선택 |
| 출력 | 직무 이름, 설명, 요구 기술과 요구 수준 |
| 선행 조건 | 없음 |
| 수용 기준 | 1. 요구 수준은 보유 숙련도와 같은 1~5 척도로 표시한다.<br>2. 로그인 상태면 "목표 직무로 추가" 버튼을 보여준다.<br>3. 로그인 상태면 "내 Skill Gap 보기"로 이동할 수 있다. |
| 예외 처리 | 없는 직무: 공통 "찾을 수 없음" 화면. |
| 관련 화면 | UI-006 직무 목록·상세 |

### FR-JOB-003 기술 검색

| 항목 | 내용 |
|---|---|
| 요구사항명 | 기술 이름 자동완성 |
| 우선순위 | Must |
| 사용자 스토리 | 구직자로서, 기술 이름 일부만 입력해도 정확한 기술을 고르고 싶다. 같은 기술을 다른 이름으로 등록하는 실수를 막기 위해서다. |
| 설명 | 2글자 이상 입력하면 표준 기술 목록에서 후보를 보여준다. 보유 기술, 프로젝트 사용 기술 입력에 공통으로 쓴다. |
| 입력 | 검색어(2~60자) |
| 출력 | 기술 후보(이름 앞부분 일치 우선, 최대 20개) |
| 선행 조건 | 없음 |
| 수용 기준 | 1. 2글자 미만이면 후보를 보여주지 않는다.<br>2. 대소문자를 구분하지 않는다(python = Python).<br>3. 같은 기술이 후보에 두 번 나오지 않는다. |
| 예외 처리 | 후보 없음: "목록에 없는 기술입니다" 안내. |
| 관련 화면 | UI-007 기술 선택 (공통 부품), UI-008, UI-010 |

### FR-JOB-004 기업 조회

| 항목 | 내용 |
|---|---|
| 요구사항명 | 기업 목록·상세 조회 |
| 우선순위 | Must |
| 사용자 스토리 | 방문자로서, 공고를 낸 기업의 정보를 보고 싶다. 지원할 회사를 판단하기 위해서다. |
| 설명 | 기업 이름 검색, 기업 상세(소개, 홈페이지, 진행 중인 공고 수, 데이터 출처)를 제공한다. |
| 입력 | 검색어(선택), 기업 선택 |
| 출력 | 기업 목록, 기업 상세 |
| 선행 조건 | 없음 |
| 수용 기준 | 1. 기업 상세에서 "이 기업의 공고 보기"를 누르면 해당 기업으로 걸러진 공고 목록으로 이동한다.<br>2. 데이터 출처를 표시한다(1차는 "가상 데이터"). |
| 예외 처리 | 검색 결과 없음 안내. 없는 기업: 공통 "찾을 수 없음" 화면. |
| 관련 화면 | UI-011 기업 목록·상세 |

### FR-JOB-005 채용공고 검색

| 항목 | 내용 |
|---|---|
| 요구사항명 | 채용공고 목록 조회와 조건 검색 |
| 우선순위 | Must |
| 사용자 스토리 | 방문자로서, 직무·기업 조건으로 공고를 찾고 싶다. 관심 있는 공고만 빠르게 보기 위해서다. |
| 설명 | 검색어, 기업, 직무 조건으로 공고를 찾고 최신 게시순 또는 마감 임박순으로 정렬한다. 기본은 게시 중인 공고만 보여준다. |
| 입력 | 검색어, 기업, 직무, 마감 공고 포함 여부, 정렬 |
| 출력 | 공고 목록(제목, 기업, 직무, 고용 형태, 근무지, 게시일, 마감일) |
| 선행 조건 | 없음 |
| 수용 기준 | 1. 선택한 조건이 주소에 남아 새로고침·공유해도 유지된다.<br>2. 마감된 공고는 기본 목록에서 빠지고, "마감 공고 포함"을 켜면 표시된다.<br>3. 다음 페이지 이동 시 중복·누락이 없다. |
| 예외 처리 | 결과 없음: 조건 초기화 버튼과 함께 안내. 허용하지 않는 정렬값: 기본 정렬로 처리. |
| 관련 화면 | UI-012 공고 목록·상세 |

### FR-JOB-006 채용공고 상세

| 항목 | 내용 |
|---|---|
| 요구사항명 | 공고 내용·요구 기술 조회와 적합도 확인 진입 |
| 우선순위 | Must |
| 사용자 스토리 | 구직자로서, 공고의 요구 기술과 내 적합도를 함께 보고 싶다. 지원할지 판단하기 위해서다. |
| 설명 | 공고 내용, 요구 기술(필수/우대, 요구 수준), 원문 링크를 보여준다. 로그인 사용자는 적합도 확인과 공고 저장을 할 수 있다. |
| 입력 | 공고 선택 |
| 출력 | 공고 상세, 요구 기술, 저장 여부(로그인 시) |
| 선행 조건 | 없음 (적합도·저장은 로그인 필요) |
| 수용 기준 | 1. 공고에 요구 수준이 없으면 직무 기본 요구 수준을 표시한다.<br>2. 마감 공고는 "마감" 표시와 함께 지원 불가 안내를 보여준다.<br>3. 비로그인 상태에서 적합도 버튼을 누르면 로그인 화면으로 이동한다. |
| 예외 처리 | 없는 공고·게시 전 공고: 공통 "찾을 수 없음" 화면. |
| 관련 화면 | UI-012 공고 목록·상세 |

### FR-JOB-007 공고 저장

| 항목 | 내용 |
|---|---|
| 요구사항명 | 관심 공고 저장·해제와 저장 목록 |
| 우선순위 | Should |
| 사용자 스토리 | 구직자로서, 나중에 다시 볼 공고를 저장하고 싶다. 여러 공고를 비교하기 위해서다. |
| 설명 | 공고 목록·상세에서 저장하거나 해제하고, 저장한 공고를 최근 저장순으로 본다. |
| 입력 | 공고 선택, 저장/해제 |
| 출력 | 저장 상태, 저장 목록 |
| 선행 조건 | 로그인 상태 |
| 수용 기준 | 1. 같은 공고를 여러 번 저장해도 한 번만 저장된다.<br>2. 목록과 상세에서 저장 상태가 같게 보인다.<br>3. 저장한 공고가 마감되면 저장 목록에 "마감"으로 표시된다. |
| 예외 처리 | 저장 목록 없음: "저장한 공고가 없습니다" 안내와 공고 검색 버튼. |
| 관련 화면 | UI-013 저장한 공고, UI-012 |
