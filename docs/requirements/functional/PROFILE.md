### FR-PRF-001 보유 기술 관리

| 항목 | 내용 |
|---|---|
| 요구사항명 | 보유 기술과 숙련도 등록·수정 |
| 우선순위 | Must |
| 사용자 스토리 | 구직자로서, 내가 가진 기술과 수준을 등록하고 싶다. 목표 직무와 비교해 부족한 기술을 알기 위해서다. |
| 설명 | 기술 목록에서 기술을 골라 숙련도(1~5)와 함께 저장한다. 목록 전체를 한 번에 저장한다. |
| 입력 | 기술(표준 기술 목록에서 선택, 최대 100개), 기술별 숙련도(1~5 또는 미입력) |
| 출력 | 저장된 보유 기술 목록 |
| 선행 조건 | 로그인 상태 |
| 수용 기준 | 1. 같은 기술은 한 번만 등록된다.<br>2. 숙련도 입력란 옆에 단계별 설명(1 입문 · 2 기초 · 3 실무 가능 · 4 능숙 · 5 전문가)을 보여준다.<br>3. 숙련도를 비우면 Skill Gap 계산 시 0으로 계산하고, 결과 화면에 "숙련도 미입력"을 표시한다.<br>4. 저장 후 홈 화면의 프로필 완성도가 갱신된다. |
| 예외 처리 | 기술이 없음(0개): "기술을 1개 이상 등록하면 분석을 받을 수 있습니다" 안내. 목록에 없는 기술: 검색 결과 없음 안내. |
| 관련 화면 | UI-008 나의 기술, UI-N02 온보딩 |

### FR-PRF-002 목표 직무 설정

| 항목 | 내용 |
|---|---|
| 요구사항명 | 목표 직무 최대 3개 선택과 우선순위 지정 |
| 우선순위 | Must |
| 사용자 스토리 | 구직자로서, 가고 싶은 직무를 골라 두고 싶다. Skill Gap과 추천을 그 직무 기준으로 받기 위해서다. |
| 설명 | 직무를 최대 3개 고르고 1~3순위를 정한다. Skill Gap 분석과 추천의 기준이 된다. |
| 입력 | 직무(최대 3개), 우선순위(1~3, 중복 불가) |
| 출력 | 저장된 목표 직무 목록 |
| 선행 조건 | 로그인 상태 |
| 수용 기준 | 1. 4번째 직무는 추가할 수 없다.<br>2. 같은 순위를 두 직무에 줄 수 없다.<br>3. 직무 상세 화면에서 바로 목표 직무로 추가할 수 있다.<br>4. 목표 직무를 바꾸면 이전 Skill Gap 결과에 "이전 기준" 표시가 붙는다. |
| 예외 처리 | 목표 직무 없이 Skill Gap·추천 화면에 들어오면 목표 직무 설정으로 안내한다. |
| 관련 화면 | UI-009 목표 직무, UI-006 직무 상세, UI-N02 온보딩 |

### FR-PRF-003 경력 관리

| 항목 | 내용 |
|---|---|
| 요구사항명 | 경력 추가·수정·삭제 |
| 우선순위 | Should |
| 사용자 스토리 | 구직자로서, 경력을 기록해 두고 싶다. 이력서 분석과 추천에 근거로 쓰기 위해서다. |
| 설명 | 회사·기관명, 직함, 기간, 설명을 기록한다. 종료일이 없으면 재직 중으로 표시한다. |
| 입력 | 회사·기관명(1~200자), 직함(1~200자), 시작일, 종료일(선택), 설명(선택) |
| 출력 | 경력 목록(최근 순) |
| 선행 조건 | 로그인 상태 |
| 수용 기준 | 1. 종료일이 시작일보다 앞이면 저장되지 않는다.<br>2. 종료일을 비우면 "재직 중"으로 표시된다.<br>3. 삭제 전 확인 창을 띄운다. |
| 예외 처리 | 기간 오류: 종료일 입력란 아래 오류 표시. |
| 관련 화면 | UI-010 경력·프로젝트 |

### FR-PRF-004 프로젝트 관리

| 항목 | 내용 |
|---|---|
| 요구사항명 | 프로젝트와 사용 기술 기록 |
| 우선순위 | Should |
| 사용자 스토리 | 구직자로서, 참여한 프로젝트와 쓴 기술을 기록하고 싶다. 실제로 써 본 기술을 적합도 계산에 반영하기 위해서다. |
| 설명 | 프로젝트명, 요약, 기간, 사용 기술(최대 30개)을 기록한다. 사용 기술은 적합도 계산에 참고 자료로 쓰인다. |
| 입력 | 프로젝트명(1~200자), 요약, 시작일, 종료일, 사용 기술 |
| 출력 | 프로젝트 목록, 프로젝트별 사용 기술 |
| 선행 조건 | 로그인 상태 |
| 수용 기준 | 1. 사용 기술은 표준 기술 목록에서만 고를 수 있다.<br>2. 종료일이 시작일보다 앞이면 저장되지 않는다.<br>3. 프로젝트를 삭제하면 그 프로젝트의 사용 기술 기록도 함께 삭제된다. |
| 예외 처리 | 기간 오류: 입력란 아래 오류 표시. |
| 관련 화면 | UI-010 경력·프로젝트 |
