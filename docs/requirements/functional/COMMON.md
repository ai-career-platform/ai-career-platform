### FR-CMN-001 홈

| 항목 | 내용 |
|---|---|
| 요구사항명 | 로그인 후 첫 화면 요약 |
| 우선순위 | Must |
| 사용자 스토리 | 구직자로서, 로그인하면 내 상태와 다음에 할 일을 한눈에 보고 싶다. 필요한 기능으로 바로 이동하기 위해서다. |
| 설명 | 프로필 완성도, 목표 직무, 최근 Skill Gap 요약, 추천 공고 상위 3개, 다음에 할 일을 보여준다. |
| 입력 | 없음 |
| 출력 | 요약 카드, 다음 할 일 목록 |
| 선행 조건 | 로그인 상태 |
| 수용 기준 | 1. 비어 있는 항목은 "기술 등록하기"처럼 해당 기능으로 가는 버튼으로 바꿔 보여준다.<br>2. 일부 요약을 불러오지 못해도 나머지 카드는 정상 표시한다. |
| 예외 처리 | 요약 일부 실패: 해당 카드만 다시 시도 버튼 표시. |
| 관련 화면 | UI-N01 홈 |

### FR-CMN-002 가입 후 온보딩

| 항목 | 내용 |
|---|---|
| 요구사항명 | 가입 직후 프로필·기술·목표 직무 입력 안내 |
| 우선순위 | Should |
| 사용자 스토리 | 새 구직자로서, 가입 후 무엇을 입력해야 분석을 받을 수 있는지 안내받고 싶다. 빠르게 첫 결과를 보기 위해서다. |
| 설명 | 가입 직후 3단계(프로필 → 보유 기술 → 목표 직무)를 차례로 안내한다. 단계마다 건너뛸 수 있다. |
| 입력 | 각 단계 입력값(FR-ACC-005, FR-PRF-001, FR-PRF-002와 같음) |
| 출력 | 저장된 프로필·기술·목표 직무, 마지막 단계 후 첫 Skill Gap 결과 |
| 선행 조건 | 가입 직후 |
| 수용 기준 | 1. 세 단계를 마치면 바로 Skill Gap 결과를 보여준다.<br>2. 건너뛴 단계는 홈의 "다음 할 일"에 남는다.<br>3. 중간에 나가도 입력한 단계까지는 저장된다. |
| 예외 처리 | 단계 저장 실패: 해당 단계에 머물며 오류 안내. |
| 관련 화면 | UI-N02 온보딩 |

### FR-CMN-003 공통 내비게이션과 약관 열람

| 항목 | 내용 |
|---|---|
| 요구사항명 | 역할별 메뉴와 약관·처리방침 열람 |
| 우선순위 | Must |
| 사용자 스토리 | 사용자로서, 어느 화면에서든 같은 메뉴로 이동하고 약관을 확인하고 싶다. 서비스를 헤매지 않고 쓰기 위해서다. |
| 설명 | 모든 화면 상단에 같은 메뉴를 두고, 역할(방문자·구직자·관리자)에 따라 메뉴를 다르게 보여준다. 하단에 이용약관·개인정보 처리방침 링크를 둔다. |
| 입력 | 없음 |
| 출력 | 역할별 메뉴, 약관 문서(현재 시행 버전) |
| 선행 조건 | 없음 |
| 수용 기준 | 1. 방문자에게는 로그인·가입 버튼, 구직자에게는 내 메뉴, 관리자에게는 관리 메뉴가 추가로 보인다.<br>2. 약관 화면은 로그인하지 않아도 볼 수 있다.<br>3. 약관은 현재 시행 버전과 시행일을 표시한다. |
| 예외 처리 | 없음 |
| 관련 화면 | UI-C02 공통 내비게이션, UI-N04 약관 |

### FR-CMN-004 공통 상태 화면

| 항목 | 내용 |
|---|---|
| 요구사항명 | 로딩·오류·권한 없음·찾을 수 없음 화면 통일 |
| 우선순위 | Must |
| 사용자 스토리 | 사용자로서, 문제가 생겼을 때 무슨 일인지와 다음 행동을 알고 싶다. 막히지 않고 서비스를 계속 쓰기 위해서다. |
| 설명 | 모든 화면이 같은 방식으로 로딩, 네트워크 오류, 로그인 필요, 권한 없음, 찾을 수 없음, 점검 중 상태를 보여준다. |
| 입력 | 없음 |
| 출력 | 상태별 안내 문구와 버튼(다시 시도, 로그인, 홈으로) |
| 선행 조건 | 없음 |
| 수용 기준 | 1. 로그인이 필요하면 로그인 후 원래 화면으로 돌아온다.<br>2. 오류 화면에 요청 번호를 표시해 문의할 때 쓸 수 있다.<br>3. 오류 문구에 시스템 내부 정보(경로, 코드 내용)를 넣지 않는다. |
| 예외 처리 | 해당 없음 (이 요구사항이 예외 처리 기준) |
| 관련 화면 | UI-C01 공통 상태 |
