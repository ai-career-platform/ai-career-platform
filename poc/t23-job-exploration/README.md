# T23 직무·기술 탐색 UI (Mock)

T19 프론트엔드 구조와 T20 공통 UI가 확정되기 전의 독립적인 작업 초안입니다. 제품 라우트나 실제 API에 연결되어 있지 않습니다. `jobs.mock.json`과 보유 기술은 가상의 예시이며, 실제 Skill Gap 분석 결과가 아닙니다.

이 폴더에서 `python -m http.server 18083 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:18083/`에서 확인합니다. 목록·검색·정렬·페이지·상세와 예시 기술 비교를 지원합니다. Mock 파일이 없거나 응답이 실패하면 오류 메시지와 재시도를 표시합니다.

T17 API, T19 앱 구조, T20 공통 컴포넌트 및 담당 확정 후 실제 계약에 맞춰 통합해야 합니다. API, 인증된 보유 기술, 네트워크/권한 상태, 배포 및 CI를 실제 서비스로 검증한 것은 아닙니다.

검색 검증: `node --test jobs.test.mjs`. 검색 결과에서 선택한 직무가 사라지면 오래된 상세 화면을 닫는다. T06 계약의 cursor 기반 조회와 직무 상세 필드는 아직 연결하지 않았다.
