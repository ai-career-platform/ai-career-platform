# T24 채용공고 탐색 Mock 초안

가상 데이터로 목록·조건 검색·상세·마감 표시·URL 조건 유지를 시연한다. T18 API, 실제 출처/권리, 요구 수준, 로그인, 실제 페이지네이션과 공용 UI는 미연결이다. T04의 요구사항은 PM 승인 전이다. 제품 구현이나 API 검증을 의미하지 않는다.

검색 검사: `node --test filter.test.mjs`. 로컬 미리보기: 이 폴더에서 `python -m http.server 18085 --bind 127.0.0.1`.

가상 공고의 게시 상태뿐 아니라 로컬 날짜 기준 마감일 경과도 마감으로 표시한다. 날짜 경계는 Mock 규칙이며 실제 T18 계약과 서버 기준시각은 확인이 필요하다. 검색 조건이 바뀌면 이전 상세를 지운다.
