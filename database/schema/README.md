## Re-generate and compare

From repository root:

```bash
python3 database/model/check_data_dictionary.py --ddl > /tmp/t05-generated.sql
sed -n '/^-- GENERATED by database\/model\/check_data_dictionary.py/,$p' \
  database/schema/T05_VALIDATION_ONLY.sql > /tmp/t05-committed.sql
diff -u /tmp/t05-committed.sql /tmp/t05-generated.sql
```

The CI workflow `.github/workflows/t05-reference-schema-check.yml` performs this comparison and also runs the isolated T10 Seed validation using PostgreSQL 18.1.

## Test-only instructions

The generated SQL begins with `BEGIN; SET search_path TO career;`, so a disposable DB needs `CREATE SCHEMA career` before applying it. **Never execute these commands against `ai_career_poc` shared Staging**. The isolated test script handles container lifecycle, schema creation, and cleanup:

```bash
D1_TEST_ONLY=YES bash database/tests/test_seed_idempotency.sh
```

Do not copy `T05_VALIDATION_ONLY.sql` to a numeric forward migration name. T05 is draft, and the current legacy `database/migrations/DRAFT_0001_initial_schema.sql` covers a different 10-table layout and is **not** compatible with the 51-table dictionary or T10 Seed.
