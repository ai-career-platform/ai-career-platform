# T24 — 기업·채용공고 탐색

상태: **PARTIAL / Draft 검토**. 경로 `/job-postings`, Redmine #1519.

정식 T18 API에서 목록/상세, 제목 검색, 기업·직무 ID 필터, 마감 포함, 게시일·마감일 정렬, 커서 이동, 요구 기술을 읽는다. 기업 카드·기업 상세·고용형태·마감일·출처 링크를 표시하고 URL의 검색·기업·직무·정렬·상태 조건을 복원한다. 옵션은 API에서 최대 100건을 읽으며 다음 커서가 있으면 일부 표시임을 안내한다. 개인 북마크는 후속 범위다. 정식 API의 상태·마감 판단을 사용한다.

## 수집 공고 개발 미리보기

선택적 미리보기는 `/api/jobs/collected`에서 최근 최대 100건을 읽고 HTTP 수집과 HTML 가져오기를 별도로 표시한다. 정식 목록과 검색 조건은 공유하지 않으며 페이지 이동도 지원하지 않는다. 미리보기에는 회사·지역·원문 URL·수집 시각만 표시하고 모집 여부, 마감일, 기술 등은 추측하지 않는다. 원문 링크는 잡코리아 HTTPS 호스트로 제한한다.

미리보기는 `VITE_T24_COLLECTED_PREVIEW=true`인 개발 서버에서만 표시되며 기본값은 꺼져 있고 프로덕션 빌드에서는 제외된다. 팀 출처 권리·서비스 표시 조건과 정식 API/DB 적재 방식 확인 전 공개 서비스 기능이 아니다. 수집 API의 `imported_html`은 실제 데이터임을 보증하지 않는다.

## 실행 및 검증

`frontend`에서 `npm ci`, `npm test`, `npm run build`. `npm run dev`는 같은 Origin `/api` 경유 실제 Backend를 사용하며, `DEV_API_PROXY_TARGET`으로 허용된 테스트 서버를 선택할 수 있다. 비밀값을 VITE 변수에 넣지 않는다. 현재 화면에 맞는 T18 Mock 핸들러가 없어 `dev:mock`은 실제 API 검증 방법이 아니다.

스테이징 조회에서 정식 API는 Seed 공고를 반환했고, 로컬 미리보기는 기존 수집 API의 HTTP 수집 기록 5건을 브라우저에 표시했다. 테스트는 가상 응답으로 필터·커서·상세·출처 분리·링크 검증 및 오류 재시도를 검사한다. 전체 실제 API E2E, 외부 표시/권리, 모바일·키보드 QA, 최신 CI·리뷰는 남아 있다.

T23과 `routes.tsx` 및 메뉴를 각각 변경하므로 한 PR 병합 후 다른 PR에서 두 경로를 모두 보존해야 한다. 공유 DB·배포 변경은 없다.
